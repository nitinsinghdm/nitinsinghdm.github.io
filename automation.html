01

The Problem

A job search spreads information across inboxes, spreadsheets, calendars, and job boards. I built a personal prototype to bring those sources behind a single conversational interface.

02

What the Exported Workflows Show

The repository contains six n8n workflow exports: a supervisor and five specialist workflows. The supervisor uses workflow tools to route a request and combines their context into a response.

  • Gmail: read inbox messages and pass prepared email data to a model with a structured output parser.
  • Applications and interviews: read Google Sheets records and prepare them for analysis.
  • Calendar: retrieve events and summarize the available context.
  • Job discovery: query an external API, prepare results, and use a language model to interpret them.
03

Why This Belongs in an Analytics Portfolio

Good analysis depends on getting the right information into a usable shape. This project shows how I connect tools, prepare inputs, structure outputs, and think through a process that crosses multiple systems.

The same integration skills can support reporting workflows and recurring operational questions. Any business deployment would need its own access controls, testing, monitoring, and a clear approval step before external actions.

04

Scope and Next Steps

This is a personal prototype with exported workflow logic. I do not present it as a production service or claim measured time savings. The exported Calendar workflow reads events; it does not establish an automated interview-booking system.

My next steps would be to test a fixed set of requests, handle API failures explicitly, and make source records visible alongside generated answers so a user can verify the response.
