01

The Question

How can transformations stay understandable as source tables and business logic grow? I organized this project around a clear path from raw sources to reusable analytical models.

02

What I Built

Bronze models reference source tables. The Silver layer joins sales, product, and customer data and uses a reusable multiplication macro. The Gold model ranks item updates with ROW_NUMBER() to keep the latest record per ID.

03

Quality and History

The repository defines unique, not-null, accepted-value, and non-negative tests. A timestamp-based snapshot tracks changes using the update_date field. These are concrete examples of how I make assumptions explicit in the transformation code.

04

What Comes Next

This is a portfolio implementation. My next steps would be to add automated build checks, orchestration, and monitoring, then document run results and failure handling.
