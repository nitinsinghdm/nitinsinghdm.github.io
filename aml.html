01

The question

How do you turn banking records into evidence an analyst can inspect? I built NorthStar Bank as a synthetic environment to connect data quality, transaction monitoring and reporting in one reproducible workflow.

02

What runs today

The preserved PostgreSQL model covers customers, accounts, beneficiaries and transactions. Python generates repeatable activity and audits accepted, rejected and replayed rows. Four SQL rules flag structuring, rapid transfers, high-risk corridors and rapid movement of funds. The public network links each alert to its payment evidence; Streamlit provides local summary analytics.

03

Evidence, with context

The public network contains 10,281 synthetic payments across 250 accounts and 74 account/day/rule alert groups. Replay payments at second resolution, jump to a UTC time or focus on the last hour. Alerts appear only when the available evidence triggers a rule. These are simulated records, not a live bank feed or findings of crime.

04

Models and transformations

PySpark produces typed silver/gold Parquet datasets reconciled against SQL. A scikit-learn classifier scores customer behavior, with 75 training customers and 25 held-out customers in the separate original analytics preview. Evaluation on injected synthetic patterns does not demonstrate real-world AML accuracy.

05

Try the interface

Open the public transaction network above to explore account connections and evidence-linked alerts without installation. For the full local analytics interface, clone the repository, install requirements-dashboard.txt and run streamlit run dashboard_app.py. The bundled preview needs no database or cloud account. To see a fresh run, generate, validate, export and train through the documented CLI, then choose My local exports. The interface reads snapshots; it does not start background jobs.

06

Delivery boundaries

The local AML workflow and dashboard are implemented and tested. Snowflake loading is implemented with environment-based credentials but still needs live-account validation. Looker Studio datasets and setup instructions are provided; no report is published. This project does not block payments, connect real bank accounts or operate as a production compliance service.
