## Website features

- Charcoal theme with lime accents and responsive layouts.
- Project filters for analytics, automation, and data engineering.
- Manual carousels combine numbered project workflows and original screenshots, with position indicators, keyboard controls, and touch swiping. Navigation arrows use CSS strokes so they cannot render as mobile emoji.
- Sticky navigation, scroll progress, and subtle section reveals.
- Keyboard focus styles, a skip link, and reduced-motion support.
- Profile and experience copy can switch between English and German. Navigation, project descriptions, and some other sections currently remain English.
- Core content stays visible without JavaScript; filters, carousels, and language switching require it.

## Preview locally

Open `index.html` in your browser. Alternatively, from the repository folder:

```bash
python3 -m http.server 8000
```

Then visit `http://localhost:8000`. Stop the server with `Ctrl+C`.

## Maintain the portfolio

1. Edit content and project links in `index.html`.
2. Update corresponding entries in `germanCopy` inside `script.js` when changing translated sections. English copy is read directly from the HTML.
3. Add screenshots under `assets/images/` and use matching, case-sensitive paths and descriptive `alt` text. Each carousel needs one initial `.active` image; multiple images need previous/next buttons.
4. Give each project a `data-category` of `analytics`, `automation`, or `engineering`. If adding/removing projects, update the visible total and initial filter-status text in the HTML.
5. Replace `assets/nitin_singh_da_cv.pdf` when the CV changes, or update both download links if renaming it.
6. Increase the CSS/JS version query strings in `index.html` after asset updates if browsers keep showing cached files.
7. Check desktop and mobile widths, EN/DE switching, all filters, carousel controls, keyboard navigation, and CV downloads before publishing.

## Publish updates

Review and commit only the files you intend to publish:

```bash
git status
git diff --check
git add README.md index.html style.css script.js favicon.svg robots.txt sitemap.xml .gitignore
git commit -m "Update portfolio content and repository documentation"
git push origin main
```

Stage any changed images or CV separately. After GitHub Pages finishes deploying, check [the live site](https://nitinsinghdm.github.io/) and hard-refresh if needed. Repository Pages settings determine which branch and folder are deployed.
