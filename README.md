# Nitin Singh | Data & Marketing Analytics

Static portfolio with English and German copy, five featured projects, including an AML project in progress, a light/dark theme, and scroll effects with reduced-motion support.

## Preview

Run `python3 -m http.server 8765 --bind 127.0.0.1` in this folder and open `http://127.0.0.1:8765/`.

## Files

- `index.html`: positioning, selected work, background, and contact.
- `ecommerce.html`, `job-market.html`, `automation.html`, `data-pipeline.html`: evidence-linked case studies.
- `aml.html`: current project direction and development status.
- `style.css`, `script.js`: responsive layout, translations, theme, and motion.
- `assets/nitin_singh_da_cv.pdf`: conservative CV aligned with the portfolio.

English and German text are embedded in each element's `data-en` and `data-de` attributes. The HTML remains readable with JavaScript disabled. Images are original project outputs. All quantitative project claims reference saved repository results; employer impact percentages and unsupported project claims have been removed.

The e-commerce 23.8% figure is derived from `(1337137.62 + 1227340.25) / 10778116.37 * 100` in the saved category and total sales exports. It describes the public project dataset, not an employer result. Salary-subset percentages in the job-market case study use 48 salary-reported German Data Analyst postings in the saved notebook output.
